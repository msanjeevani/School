# 🏫 EduFlow – School Management System

> A modern, responsive and interactive School Management System designed to manage students from **Pre-KG to Grade 12**.

EduFlow is a frontend-based School Management System that provides a centralized dashboard for managing students, teachers, attendance, examinations, results, student progress, fees, transport, notifications and parent communication.

The project is designed with a professional UI, responsive layout, interactive JavaScript functionality and animated user interactions.

## 👥 User Roles

### 👨‍💼 Administrator

Administrators can manage:

- Students
- Teachers
- Attendance
- Examinations
- Results
- Student Progress
- Timetable
- Fees
- Transport
- Notifications
- Parent Portal
- School Settings

### 👩‍🏫 Teacher

Teachers can:

- View students
- Manage attendance
- Manage examination marks
- View student progress
- Communicate with parents
- View class information

### 👨‍👩‍👧 Parent

Parents can:

- View child profile
- Check attendance
- View examination results
- Track academic progress
- Check fee status
- View timetable
- Receive notifications
- Contact teachers/school

### 👨‍🎓 Student

Students can view:

- Profile

- Academic progress
- Timetable
- Assignments
